# SOLARIS CET — dosare pentru instalații fotovoltaice

**Documentele unei instalații PV, gata de semnat — generate din 3 poze pe WhatsApp.**

SOLARIS CET S.R.L. este o firmă de software (CUI 55619552, CAEN 6210) din București care întocmește
**dosarul de prosumator** pentru operatorul de distribuție și **dosarul de predare** către clientul final,
pentru firmele care montează sisteme fotovoltaice în România.

## Cum funcționează

1. **Trimiți** pe WhatsApp pozele etichetelor echipamentelor (panouri, invertor, baterie, protecții),
   numele clientului și operatorul de distribuție.
2. **Generăm și verificăm** documentele pe numele și logo-ul firmei tale, comparăm seriile,
   întocmim raportul de verificare.
3. **Primești** PDF-urile numerotate, arhiva ZIP cu documentele individuale pe roluri și codul QR
   de verificare a autenticității.

## Ce **nu** facem — ca să nu existe așteptări greșite

- Nu montăm instalații și nu vindem echipamente.
- Nu proiectăm și nu facem măsurători (priză de pământ, izolații) — le face persoana atestată ANRE.
- Nu semnăm în locul firmei tale și nu depunem dosarele la operator sau la client.
- Nu garantăm acceptarea de către operator; garantăm documentele pe care le generăm
  (corectăm gratuit orice eroare a noastră).

## Tehnologie

Aplicația web este construită cu **Next.js 15 + React 19 + TypeScript**, generare PDF server-side,
arhive ZIP cu amprente SHA-256, workers pentru procesarea imaginilor și un pipeline de verificare
înainte de livrare. Documentele se generează din date structurate, nu din șabloane completate manual.
